**What you'll build:** An uptime board that checks three web addresses, keeps the history in a database and turns red with an alert when one goes down, live on the internet as a Codex Site. You describe it, Codex builds and deploys it. About 20 to 30 minutes.

**You need:** the Codex app, signed in, with Sites. On a Free or Go plan, redeem the sponsored month Codexing gives you first. Nothing to clone: this ticket doesn't use the LedgerLoop code.

**Easiest way in:** in Codex, say `@Codexing start`. It checks your computer is ready and hands you this ticket.

### Do it yourself

In Codex, open a new empty folder, start a chat, switch on plan mode and paste this:

```text
@Sites Build an uptime board with alerts and deploy it as a Site, with a Sites database for the history. Watch three URLs: https://api.codexxing.id8devhub.com/v1/health (always up), https://api.codexxing.id8devhub.com/v1/health/down (always down, so we can see the alert work) and this Site's own home page. Each check saves the time, HTTP status, response time and up or down in the database. The page shows each URL green or red with its last check and its uptime over the last 24 hours, and a red banner listing anything that is down. Add a Check now button, and run the checks when the page opens if the last run is over a minute old. Serve /api/status as JSON: checks (each with url, ok, status_code, latency_ms, checked_at and uptime_24h) and alerts (the URLs that are down).
```

Approve the plan, let Codex build and deploy, and open the link it gives you.

### Done when

The board shows `…/v1/health/down` in red under the alert banner and `…/v1/health` in green.

### Get it verified

Share the Site with anyone with the link. Then say **Codexing, check my work** and paste the link. Codexing reads your live Site and a hidden check decides; only the Site's link is sent.

### Stretch (advanced)

Run the checks on a schedule if your Sites plan offers scheduled tasks (otherwise say why and keep the on-open checks), send one alert per outage to a webhook kept in the Site's secrets, and mark a check slower than 2 seconds as degraded.
