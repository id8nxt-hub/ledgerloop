Three small, independent chores. Start from `t3-base` (`git switch -c sweep t3-base`).

1. **Slow payment history.** `GET /api/customers/:id/payments` gets slower with every invoice a
   customer has. It should not.
2. **Build drift.** `pnpm install --frozen-lockfile` fails on `t3-base`, so CI is red before any
   test runs. The lockfile and the manifests should agree again.
3. **Stale pull request.** Branch `pr/settlement-bank-credit` adds the bank's credited amount to
   the settlement report, but it was cut before the report gained refunds and no longer merges.
   Bring it up to date so the report has both.
